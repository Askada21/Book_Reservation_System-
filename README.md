# 📚 Book Reservation System

## 📌 Project Overview

A web-based Book Reservation System developed as part of my second-year Web Development assignment at Technological University Dublin (TU Dublin).

The application allows users to register, log in, search for books, reserve available books, and manage their reservations.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (planned)
- **Backend:** PHP
- **Database:** MySQL
- **Development Environment:** XAMPP, phpMyAdmin
- **Version Control:** Git & GitHub
- **IDE:** Visual Studio Code


## 📂 Project Structure

```text
Book_Reservation_System/
├── index.php
├── db.php
├── register.php
├── login.php
├── logout.php
└── README.md
```

## 🚀 Running Locally

1. Install and start XAMPP (Apache and MySQL).
2. Place the project folder inside XAMPP's `htdocs` directory.
3. Create the MySQL database and required tables using phpMyAdmin.
4. Configure the database connection in `db.php`.
5. Open `http://localhost/Book_Reservation_System/` in your browser.
